Keep your music safe first. Avoid uninstalling or clearing app data to troubleshoot. We have no cloud copy of your local library; export a backup before important changes.

2. Import and discover music

How do I add my first songs?

Use “+” in the library to scan device audio, import files or open browser Wi-Fi transfer. An empty library also displays import shortcuts. When automatic discovery is enabled, accessible media is discovered according to system permissions and scan settings.

Android primarily uses the system media library and explicitly authorized folders. On iPhone/iPad, select audio or folders in Files, use Finder file sharing or open audio in Music from another app. Music does not automatically read other apps’ private libraries.

Files are missing, or voice recordings appear as music.

Check Settings → Media scanning for short-audio, size, system-sound and folder filters, then refresh. Authorize an automatic-discovery folder or import files directly if the system has not indexed them. Android 11+ generally prevents access to another app’s private Android/data directory; export from that app to Download/Music first.

Changed filters apply mainly to future scans and do not automatically delete existing items. Remove unwanted recordings from the library; deleting a managed copy is a separate action. Scanning cannot make encrypted, DRM-protected or damaged files playable.

An iCloud or cloud-drive file will not import.

First download it in Files and confirm it opens, then select it again. Automatic folder discovery skips undownloaded cloud placeholders so a network download does not block the scan. Reauthorize expired folder access and check that your cloud provider is signed in.

3. Computer transfers and playlist capsules

The browser opens, but uploads, drag-and-drop or downloads fail.
  1. Connect your computer and phone to the same trusted network or phone hotspot. Keep Music visible in the foreground.
  2. Open + → Wi-Fi transfer, enter the displayed address in the computer’s browser and enter the phone’s pairing code.
  3. Try one ordinary MP3/FLAC first. If dragging is blocked, use the file or folder picker. Check phone storage and per-file import results.
  4. Allow multiple downloads in the browser if “select all” is blocked, or try downloading one song.
  5. After a network change, session expiry or background interruption, reopen the transfer session and refresh the browser. Do not reuse an old pairing code.

Supported ZIP music packages can be imported, but not every encrypted archive, compression method or archive layout is supported. Collapsing the in-app panel allows other foreground use; locking the device or switching apps may interrupt the connection.

Can a friend receive a playlist without installing Music?

Open face-to-face sharing / playlist capsule from a playlist or song menu. Choose whether to include audio, artwork and lyrics. On a reachable shared network, the recipient can use their system camera to open the share code and download a ZIP in the browser; installed devices can open Music to receive it.

A metadata-only playlist package is not a substitute for audio files. Links normally expire after 20 minutes or when sharing stops; generate a new one if necessary. Valid links can be forwarded, so share only with trusted people.

4. Connections and Local Jam

Can we share or listen without a shared Wi-Fi router?

Turn on one device’s hotspot and connect the other phone, tablet or computer to it. Return to Music, create a room or share, then scan the invitation. Supported Android devices can create a local-only hotspot from hotspot help without sharing mobile data. First scan its Wi-Fi code with the system camera to join the network, then return to Music to scan the room or capsule code. An iPhone hotspot normally starts in system settings.

The Wi-Fi join code and room invitation are different. Two devices using separate mobile-data connections cannot currently connect directly; no public-internet relay is provided.

Scanning fails with “No route to host,” a timeout or connection refusal.

Confirm both devices are on a reachable network. Allow Local Network access on iPhone/iPad/Mac, and camera access on the scanning device. Check guest-network or client-isolation settings, temporarily disable a VPN that may block local traffic, or try a phone hotspot.

After switching networks, let the host return to Music, refresh addresses and show a fresh invitation. If a browser cannot reach a capsule’s first address, the sender can choose “Browser cannot open? Switch sharing address.” You can paste the complete invitation instead of scanning. Keep its credentials intact; an IP address alone is insufficient.

Playback lags, disconnects or fails to follow a track change.

Update both devices to compatible current versions. Use a stable network and reduce concurrent large-file transfers. Try device speakers to isolate Bluetooth headphone latency. The host should play independently without waiting for a guest’s file transfer.

Current streaming rooms do not automatically add every song to the guest’s library. Use “Save to my library” in the player menu to keep one; compatibility with older versions may download a file first. If the issue persists, report both devices and versions, network type, audio outputs, roles and track-change steps. Output latency varies; zero-delay playback is not guaranteed.

5. Bump sharing and NFC

A gentle bump does nothing, or sharing works only once.

Open the player and enable bump sharing on both supported phones. Allow Bluetooth/nearby-device access; some Android versions also require location services. Both devices still need a reachable shared network or hotspot, and at least one needs a current shareable song. Detection combines Bluetooth proximity with motion events; it is not precise five-centimeter ranging.

Keep both apps in the foreground, wait for ready status and check compatible send/receive modes. Turn bump sharing off and on if necessary. Do not strike devices forcefully. Use QR/capsule sharing if detection remains unreliable, and report whether the ready state failed to return after the first transfer.

Is NFC the same as phone-to-phone bump sharing?

Phone bump sharing uses Bluetooth discovery, motion detection and local network transfer. The separate NFC reader reads tag content on supported hardware and systems. Enabling NFC does not connect a hotspot or guarantee phone-to-phone NFC file transfer. Macs, iPads and some phones lack equivalent proximity features; use QR invitations, pasted links or files instead.

6. Playback, lyrics and external storage

Playback stops, a source is missing or a format will not play.

Check the song’s file details first. Moving or deleting files, disconnecting storage or revoking a folder grant can break a source; relocate it or import it again. Android battery restrictions can interrupt background playback. Force quitting Music on iOS stops audio.

For decoding failures, report the extension, codec if known, size and error message. You do not need to send the complete audio file initially. Encrypted streaming-service downloads generally cannot play as ordinary local audio.

Lyrics are missing or mistimed, or a NAS connection succeeds but will not play.

Lyrics can come from a local edited copy, embedded tags or a readable matching LRC/TXT sidecar. Import them or adjust timing in the lyric panel. Music does not scrape lyric websites or rewrite original audio tags.

Storage sources currently save settings and test WebDAV connectivity. Full SMB mounting, remote directory browsing and remote-library playback are not available. A successful connection test does not enable those capabilities. Download and import files through a system file provider when needed. Prefer HTTPS and a limited-permission WebDAV account.

7. Platform permissions and privacy requests

Where do I revoke permissions on Apple devices and Android?

iPhone/iPad: check Music’s app settings or Privacy & Security in system Settings for camera, local network and Bluetooth access. Remove saved folders in Music’s folder management. Mac: check camera, local network or file access in System Settings → Privacy & Security, and reselect files to authorize them. Available controls vary by system version.

Android: use Settings → Apps → Music → Permissions for audio/music, video and nearby devices. Some older systems also tie Bluetooth or hotspots to location services. You can import selected files without all-files access. Revocation does not delete imported copies; clearing app data can delete your local library, so back it up first.

How do I delete my account or data, or withdraw permission?

Music currently has no registration and no account-deletion button. Use the relevant remove-from-library, delete-managed-copy or data-cleanup controls for local data. Delete external backups and recipients’ copies separately. You can stop transfers, leave rooms, disable bump sharing and revoke folder/system access.

For support messages or attachments you sent us, email onebestai@gmail.com with “Music privacy request.” See the privacy rights section for the process and applicable rights. Deleting Music does not close your Apple, Google or cloud-drive account.

Why is the local address HTTP, and is it secure?

Current local transfers do not provide TLS or end-to-end encryption. Pairing codes and temporary links restrict access but do not replace transport encryption. Use trusted networks, keep codes/tokens private and avoid public port forwarding. See transfer security and the Apple platform / Google Play terms for the relevant boundaries.

8. Backup, migration and deletion

Use Settings → Export and restore to create a migration archive, choosing audio and lyrics where needed. Store it outside Music and verify important files before migration, cleanup or uninstalling. Restore primarily merges data; archives without audio require sources to be relinked.

  • Remove from library: removes references and related organization data, normally retaining audio copies.
  • Delete managed copy: deletes the audio copy created by Music and cannot be undone; it is not deletion of an external original.
  • Remove a folder or source: ends future access or removes settings; imported songs are not automatically deleted.
  • Shared data: recipients manage their own received songs and backups. We cannot remotely recall them.

See the Privacy Policy for details.

9. What to include in a report

  • Music version, operating-system version and device model, for both sides of a connection issue.
  • Where you started, the exact steps, expected and actual behavior, and the complete error text.
  • Wi-Fi/hotspot type, host/guest roles and speaker, wired or Bluetooth output.
  • Relevant screenshots or a file from Settings → Preview diagnostic export. You must explicitly share the file; it is not sent automatically.

Before sending, hide private paths, playlist information, QR codes, invitation tokens, pairing codes and account details. Do not send passwords, hotspot credentials, unauthorized songs or a full library backup. We will explain any further information needed.
