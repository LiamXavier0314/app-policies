1. 适用范围、提供方与联系

本政策适用于 Music（本地音乐）在 iOS、iPadOS、macOS、Android（包括通过 Google Play 发行的版本）上的应用，以及本网站的相关支持。Music 使用 Manna Studio 品牌维护和发布，隐私事务联系人为维护团队，邮箱：onebestai@gmail.com。具体版本的发行开发者信息见你下载安装时的应用商店产品页；若发行主体变更，我们会同步更新本政策。

本政策同时说明设备本地处理和由你选择的联网处理。不同平台、硬件、发行渠道及版本的能力不同，没有出现在你的设备上的功能不会仅因列入本政策而被启用。“本地优先”不表示任何数据都不会离开设备，也不表示你已同意所有可选数据传输。

2. 保存在设备上的信息

为提供播放与管理功能，Music 会在本机处理和保存：

  • 媒体与文件信息：导入或扫描的音频、视频、歌词、封面、文件名称、来源位置、大小、时长、标签，以及用于识别重复内容的文件指纹。部分导入方式会在应用存储中生成媒体副本。
  • 曲库与偏好：歌单、收藏、播放历史、播放队列与进度、歌词编辑副本、音效、语言、扫描过滤和其他设置，以及导入结果与失败原因。
  • 目录授权：Android 的持久目录访问授权、Apple 平台的安全书签及关联路径，用于再次访问你选择的目录。这些授权不让我们读取其他应用的私有目录。
  • 外部存储配置：你填写的服务名称、地址、共享路径、用户名和密码（如有），保存在本机应用数据库中。当前不应将它视为专用加密密码库，请使用权限受限的专用账户。
  • 系统媒体展示：为提供锁屏控制、通知和桌面组件，必要的曲名、歌手、封面与播放状态会交给系统媒体服务；Apple 桌面组件可通过本机 App Group 读取播放快照。锁屏可见内容受系统设置影响。

核心曲库、播放和管理功能无需账号。我们不将你的曲库自动上传到维护团队的服务器，不嵌入广告、用户画像、第三方分析或自动崩溃上传 SDK。

媒体文件及标签可能包含你或第三人的声音、姓名、图片、位置描述或其他私人信息。Music 将其作为你选择管理的媒体处理，不据此分析健康、身份或兴趣画像；分享前请自行检查文件内容。内容指纹用于去重与匹配，不是用于跨应用广告跟踪的标识。

Music 不提供公共互联网音乐托管、自动云同步或跨公网共听中继。局域网/热点功能要求设备网络可达。系统文件选择器中的网盘、系统分享目标及第三方服务器可能独立处理数据；我们不控制它们的保存、日志和删除方式。

4. 权限及其用途

权限 / 系统能力用途与选择
媒体、文件与目录访问Android 音频/视频权限用于查询系统媒体库；较旧系统可能请求存储权限。也可只通过系统选择器导入明确选择的文件或目录。iOS/iPadOS 不会全盘扫描其他应用。

本地网络 / 网络访问用于浏览器传歌、胶囊、共听、碰传，以及你配置的外部服务器连接。拒绝后本地已有媒体仍可播放。
蓝牙 / 附近设备用于碰一碰的广播、发现和连接；Android 附近 Wi-Fi 权限也可能用于创建本地热点。
位置权限与位置服务（部分 Android 系统）部分系统将蓝牙扫描或本地热点 API 与位置权限/位置服务绑定。Music 不据此建立地理位置轨迹，不以此功能读取 GPS 坐标。

NFC在受支持设备上按操作读取音乐胶囊相关标签；这与蓝牙碰一碰是不同功能。
后台音频、媒体通知与保持唤醒用于持续播放、系统播放控制，以及操作系统允许的音频运行。不会因此获得麦克风录音能力。

你可以在系统设置中撤销权限，也可以删除已保存的目录授权。撤销权限会影响对应功能，但不会自动删除已经导入的副本。Music 不要求麦克风权限来进行听歌、扫码或碰一碰。

7. 广告、跟踪、出售与自动化决策

当前 Music 不提供行为广告，不集成广告标识符跟踪或跨应用/网站跟踪，不出售或出租你的个人信息，不为跨情境行为广告共享信息，不用本地媒体建立营销画像或训练 AI 模型。曲库的排序、过滤、去重和播放同步不属于对你产生法律或类似重大影响的自动化决策。

我们不因你行使隐私权利而收取差别价格、降低基本服务或设置惩罚，也不提供以出售个人信息为条件的经济激励。在美国州隐私法有关“出售”“共享”或定向广告的规定适用时，当前没有此类活动供你退出；你仍可随时停止可选传输并提交权利请求。

应用不通过网页 Cookie、指纹或隐蔽标识追踪你的浏览行为。Apple 或 Google 自身依据你的系统/商店设置进行的诊断、备份、商店交易或账户处理，由其各自政策管理，不应被当成 Music 自动向开发者上传的曲库数据。

8. 传输安全与分享边界

本地连接使用会话令牌、配对码或临时链接限制访问，但当前局域网 HTTP 传输不提供 TLS 或端到端加密。配对码、临时链接和文件内容可能面临同一不可信网络中的监听风险。请使用自己信任的 Wi-Fi 或热点，不要通过路由器端口映射将服务暴露到公网。

浏览器传歌与歌单胶囊使用临时会话，通常在 20 分钟后到期，也可主动停止。已发送的文件、接收方保存的副本、浏览器下载和导出的备份不会因为会话到期而被远程删除。一起听请通过退出/关闭房间结束；碰一碰请关闭对应开关。

外部 WebDAV 若使用 HTTP，账户认证也缺少传输加密保护。请优先使用可信 HTTPS 服务与最小权限账户。我们不承诺任何网络或本机数据库具有绝对安全性。

我们限制临时链接的作用范围和有效期，并使用系统沙盒、访问授权、配对与会话验证等降低未经授权访问的风险。这些措施不改变当前明文 HTTP 的事实，也不表示已通过独立安全认证。若获知涉及我们实际持有个人信息的安全事件，我们会采取合理处置措施，并在适用法律要求时通知受影响用户或监管机构。

9. 支持邮件、诊断与网页访问

你主动联系我们时，我们会收到邮件地址、来信内容，以及你选择提供的设备信息、截图或附件，仅用于处理请求和必要的后续沟通。邮件提供方也会按自身政策处理邮件。

应用内诊断导出需要你预览并主动通过系统分享交付，不会自动上传。当前诊断文件主要包含生成时间、系统平台、曲库版本及数量、来源可用性、导入批次标识、状态与原因码；不会主动附带整首音频、存储源密码或完整曲库。自行添加的截图、系统日志或备份可能含有更多私人信息，发送前请检查。

这些法律与支持网页本身不设置分析脚本、跟踪 Cookie 或第三方字体。网页托管服务在交付页面时仍可能处理 IP 地址、浏览器信息和请求日志；通过 GitHub Pages 提供时，参见 GitHub 隐私声明。访问网页与本机曲库处理是不同的数据场景。

应用依赖的播放、文件选择、扫码、数据库和系统分享组件用于实现相应功能，不因被称为“第三方组件”就自动成为接收曲库的云服务。外部文件提供方、服务器、分享目标、网页托管方和邮件提供方则可能按各自政策实际接收数据，具体取决于你选择的操作。我们不以第三方组件为理由免除应由开发者承担的责任。

除你请求的分享/连接和必要服务处理外，我们仅在适用法律要求、有效法律程序或依法保护生命安全和合法权益确有必要时，披露我们实际持有的最少信息；不会因此获取我们原本不持有的本机曲库。

10. 数据所在地与跨境处理

本机曲库默认保存在你的设备。你可以自行选择其他国家/地区的 WebDAV、网盘、邮件或文件接收者；服务端位置与处理范围由该服务和你的选择决定。技术支持邮件和网页托管也可能由服务提供方在你居住地之外处理，我们不能仅凭邮箱或域名保证其物理存储国家。

如果我们负责的个人信息处理构成受适用法律约束的跨境传输，我们会按要求采取适当保障措施，例如适用的合同安排、必要说明、同意或其他法定机制；不会以本政策作出一揽子的跨境同意。若想了解与你请求相关的接收方及保障措施，可通过联系邮箱询问。你主动选择的外部服务也需遵守其自身适用规则。

11. 保存、删除与备份

  • 本机数据：曲库、设置和已导入副本通常保留到你删除、清理应用数据或卸载应用。操作系统的应用备份与设备迁移设置可能保留或恢复数据副本。
  • 操作区别：“从库移除”主要删除库引用与整理关系；“删除管理副本”删除应用生成的音频副本，不能恢复。两者不会自动删除你在其他应用、外部目录或其他设备中的原件。
  • 外部连接：可在存储源管理中删除保存的连接配置，并在授权目录管理中移除目录。删除连接配置不删除服务方的账户或日志。
  • 导出文件：备份、迁移包、下载和接收方副本由保存它们的一方管理。你需要分别从文件管理器、云盘或接收设备中删除。
  • 支持通信：来信与附件仅在处理请求、必要后续沟通、处理争议或履行适用法律义务所需期间保留。你可联系请求删除；法定保留义务及必要存档除外。

我们没有你的本机媒体云副本，因此无法替你恢复已删除的歌曲、歌单或歌词。清理与换机前请自行导出并核验备份。

临时会话令牌在会话结束、过期或重建后不再用于授权；已导入项目仍按曲库保留规则保存。传输、导入与兼容播放可能生成暂存文件或缓存，取消、任务完成和系统清理会影响其保留，不能将“退出房间”理解为对所有已产生文件的安全擦除。撤销权限或关闭功能也不能删除对方已收到的内容。

应用当前没有注册账户、云账户资料或账户注销流程。要停止使用，可先导出需要的文件，再删除本机内容和应用，并单独删除外部备份；若希望删除已发给支持渠道的信息，请通过联系邮箱提出。删除 Music 不会注销 Apple 账户、Google 账户、网盘或 WebDAV 账户。对于必须依法保留的支持记录，我们会说明保留理由，并限制其他用途。
